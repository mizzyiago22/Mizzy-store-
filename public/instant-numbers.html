How It Works & Refund Rules

  • Your wallet is charged the moment you buy, which reserves a working number for you
  • You have about 20 minutes to receive the SMS code
  • If a code arrives in time, the sale is final and you keep the code
  • If no code arrives in time, you are refunded automatically
  • You can cancel for a full refund only before a code arrives
